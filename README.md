## Data Setup

The `data/` directory is excluded from version control due to large file sizes.

To run this project, download the following files from Kaggle and place them in a `data/` directory at the project root:

- [`US_youtube_trending_data.csv`](https://www.kaggle.com/datasets/rsrishav/YouTube-Trending-Video-Dataset/data?select=US_youtube_trending_data.csv)
- [`US_category_id.json`](https://www.kaggle.com/datasets/rsrishav/YouTube-Trending-Video-Dataset/data?select=US_category_id.json)

Your directory should look like this:

```text
data/
    US_youtube_trending_data.csv
    US_category_id.json
```
